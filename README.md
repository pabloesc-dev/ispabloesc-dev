### 🏃 Análise de Dados — Corrida Internacional de São Silvestre

Projeto de coleta, tratamento, organização e armazenamento de resultados históricos da corrida.

**Tecnologias:** Python, Pandas, Requests, Selenium, SQL e PostgreSQL.

**Objetivos:**
- Desenvolver um fluxo de coleta e processamento de dados.
- Estruturar e armazenar os resultados em um banco de dados relacional.
- Explorar os dados para identificar padrões e tendências.
- Desenvolver visualizações e comunicar os resultados por meio de storytelling com dados.
